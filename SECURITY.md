# Security reports

This repository is currently private. Report a suspected vulnerability to its
maintainer, [@lpotepa](https://github.com/lpotepa), through an established private
channel. Do not put vulnerability details in a public issue.

Include the SDK and CLI versions, runtime mode, browser version, and a minimal
reproduction. Include the engine release identifier when available. Remove
credentials, license tokens, signing keys, and unrelated guest data.

The SDK and CLI are separate from the proprietary execution engine and guest
images. A report should identify which component failed. Experimental runtime
support and development signatures are not security or release certifications.
