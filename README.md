# OxideVM SDK

The Apache-2.0 TypeScript SDK and CLI for running Linux applications in a
browser with OxideVM.

This is a private preparation repository. The initial commit establishes its
content rules and license. The SDK source has not been exported here yet.

Maintainers develop changes in the authoritative SDK repository and export
reviewed source revisions here. Reviewed external contributions return through
that source before the next export. See [AGENTS.md](AGENTS.md) for the approved
structure and development rules. `CLAUDE.md` links to the same instructions.

The SDK does not contain engine binaries or guest images. The OxideVM engine
is distributed separately under its own license. Public source availability,
package publication, and runtime distribution have separate release gates.
