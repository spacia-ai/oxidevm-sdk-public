# Starter fonts

These self-hosted Latin variable fonts match oxidevm.dev. Archivo and JetBrains
Mono use SIL OFL 1.1. Roboto uses the license included in Roboto-OFL.txt.
Keep all three accompanying license texts when you copy the starter.

Sources: [Archivo](https://github.com/Omnibus-Type/Archivo),
[Roboto](https://github.com/googlefonts/roboto-3-classic),
[JetBrains Mono](https://github.com/JetBrains/JetBrainsMono).
Exact original assets:

- https://oxidevm.dev/assets/archivo-latin-wdth-normal-DY7AcnAa.woff2
- https://oxidevm.dev/assets/roboto-latin-wght-normal-ccAYIvAh.woff2
- https://oxidevm.dev/assets/jetbrains-mono-latin-wght-normal-B9CIFXIH.woff2

Embedded font metadata identifies Archivo 2.001, Roboto 3.015 (2026) and
JetBrains Mono 2.211. The repository policy pins each WOFF2 file by SHA-256.
