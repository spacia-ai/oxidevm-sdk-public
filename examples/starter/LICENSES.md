you redistribute their code. The build copies these materials into licenses/.
Dependency notices remain with their components. Fonts retain the OFL license
files in public/fonts. Python syntax highlighting uses highlight.js 11.12.0
under BSD-3-Clause. Its complete license is in public/licenses/highlight.js.txt.

development, including work on commercial projects. Commercial production
requires a Spacia agreement. Non-commercial hosted deployments follow the
existing public-license process. Development and production use the hosted runtime by default. The creator
installs no engine files in the project. Licensed self-hosting requires explicit rights and configuration.

license texts, SBOMs, checksums, and corresponding sources accompany its
binary. Engine restrictions do not restrict the rights granted by those
licenses. See the image's OPEN-SOURCE-NOTICE.md for redistribution materials.
